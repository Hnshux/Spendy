# Spendy Pro 🪙

Spendy Pro is a sleek, hyper-minimalistic, ultra-modern progressive personal and business expense tracking application built explicitly for speed and elegant micro-interactions.

Designed with a premium high-contrast Slate Charcoal aesthetic, Spendy provides immediate analytical clarity over your cash flow architecture.

## Key Blueprint Highlights
* **Dual Runtime Engine:** Effortlessly cycle architectural states between a standard standard dynamic **Personal Wallet Tracker** and **Business Pro** operations.
* **Custom Notification Engine:** Outfitted with an integrated Custom JavaScript Toast and Intercept Layer, bypassing regular browser alert frames with highly interactive contextual notifications.
* **Granular Analytics:** Realtime dynamic ChartJS rendering for compositional spending insight, structured alongside a 14-day chronological heat map tracker.
* **Instant Accounting Exports:** Single-click compilation into clean, high-table format PDF Ledger Statements via automated script compilation.

## Tech Stack Infrastructure
* **Markup & Structure:** Semantic HTML5
* **Styling Matrix:** Pure Vanilla CSS3 Custom Variables (`:root`) & Smooth Bezier Transitions
* **Logic Core:** Functional ES6 JavaScript
* **Dynamic Graphic Layer:** ChartJS Dependency Engine
* **Export Protocol:** jsPDF Table Structuring
* **Database Pipeline:** Integrated Firebase Realtime DB Module

## Deployment Setup
1. Clone this repository directly onto your local environment.
2. Ensure `index.html`, `style.css`, and `app.js` are stored parallel within the same directory.
3. Serve via standard local environment server wrappers (e.g., VS Code Live Server) or deploy directly onto structural CDNs such as **GitHub Pages**.
